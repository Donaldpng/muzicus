# MUZICUS

Свободный музыкальный плеер для **Windows** и **Android** (Tauri 2 + React + Rust).

## Возможности

- Плейлисты: обложка, название, перемешивание и повтор для каждого плейлиста, перестановка треков
- Свои аудиофайлы (mp3, flac, m4a, ogg, opus, wav), теги и обложки читаются автоматически
- Перенос плейлистов (только метаданные): YouTube / YT Music, Spotify, Deezer, Яндекс Музыка, Apple Music, SoundCloud, а также импорт текстом «Исполнитель - Название»
- Плеер: пауза, переключение треков, повтор (выкл / очередь / трек), перемешивание, перемотка
- Скорость 0.5–2x с сохранением тональности или без неё (эффект nightcore / slowed)
- 10-полосный эквалайзер с предустановками и предусилителем
- Синхронизированные тексты песен (LRCLIB)
- Настраиваемый визуализатор: полосы, зеркало, осциллограф, круг, HUD-сетка, LED-блоки; цвет, плотность, чувствительность, плавность, пики, свечение
- Тёмная (по умолчанию) и светлая тема, выбор акцентного цвета
- Автообновление: Windows через подписанный `latest.json`, Android через проверку релизов GitHub и загрузку APK

## Источник аудио: текущее состояние

Онлайн-воспроизведение через YouTube Music (библиотека `rustypipe`) **сейчас не работает**:
YouTube требует PO-токены, и поток обрывается примерно после 1 МБ. Поиск и импорт метаданных
работают, а надёжного онлайн-источника пока нет. Полностью работают свои файлы и всё, что с ними связано.

## Разработка

```bash
npm install
npm run tauri dev
```

Нужны Node.js 20+, Rust stable и MSVC Build Tools (Windows).

## Релиз

```bash
npm run release -- 0.2.0 "что нового"
```

Скрипт поднимает версию в `package.json`, `tauri.conf.json` и `Cargo.toml`, создаёт коммит и тег `v0.2.0`
и отправляет их в репозиторий. GitHub Actions собирает установщик для Windows и APK для Android и
публикует их в релизе.

Секреты репозитория:

| Секрет | Назначение |
|---|---|
| `TAURI_SIGNING_PRIVATE_KEY` | подпись обновлений Windows (`~/.tauri/muzicus.key`) |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | пароль ключа (пустой) |
| `ANDROID_KEYSTORE_B64` | release keystore в base64 |
| `ANDROID_KEYSTORE_PASSWORD` | пароль keystore |
| `ANDROID_KEY_ALIAS` | алиас ключа |

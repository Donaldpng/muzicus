# MUZICUS

Свободный музыкальный плеер для **Windows** и **Android** (Tauri 2 + React + Rust).

## Возможности

- Плейлисты: обложка, название, перемешивание и повтор для каждого плейлиста, перестановка треков
- Свои аудиофайлы (mp3, flac, m4a, ogg, opus, wav), теги и обложки читаются автоматически
- Перенос плейлистов (только метаданные): YouTube / YT Music, Spotify, Deezer, Яндекс Музыка, Apple Music, а также импорт текстом «Исполнитель - Название»
- Плеер: пауза, переключение треков, повтор (выкл / очередь / трек), перемешивание, перемотка
- Скорость 0.5–2x с сохранением тональности или без неё (эффект nightcore / slowed)
- 10-полосный эквалайзер с предустановками и предусилителем
- Синхронизированные тексты песен (LRCLIB)
- Настраиваемый визуализатор: полосы, зеркало, осциллограф, круг, HUD-сетка, LED-блоки; цвет, плотность, чувствительность, плавность, пики, свечение
- Тёмная (по умолчанию) и светлая тема, выбор акцентного цвета
- Автообновление: Windows через подписанный `latest.json`, Android через проверку релизов GitHub и загрузку APK

## Откуда берётся музыка

- **Каталог и поиск** — RustyPipe получает метаданные песен и обложки непосредственно из YouTube Music; результаты поиска — музыкальные треки, не общая выдача YouTube.
- Треки YouTube Music воспроизводятся через yt-dlp, используя ссылку `music.youtube.com`; поиск не запускает yt-dlp.
- Deezer остаётся дополнительным источником чартов и 30-секундных превью, но не используется для поиска треков.
- **Полные версии** — открытые площадки, поиск по совпадению названия, исполнителя и длительности:
  - Audius (без ключа)
  - Internet Archive (без ключа, только свободные лицензии и общественное достояние)
- Если полной версии нигде нет, играет официальное 30-секундное превью Deezer.
- Всё найденное можно скачать на устройство и слушать офлайн.
- Вкладка поиска «Открытые источники» ищет сразу по этим площадкам: там каждый трек доступен целиком.
- Никаких ключей и регистраций не нужно.
- Вкладка поиска «YT Music» — основной каталог; «Открытые источники» доступна отдельной вкладкой.
- Потоки yt-dlp воспроизводятся через локальный Axum HTTP-прокси с поддержкой Range и CORS, поэтому Web Audio API продолжает работать для эквалайзера и визуализатора.

Мейнстримные релизы крупных лейблов на открытых площадках встречаются редко, поэтому для них
обычно доступно только превью.

На Windows MUZICUS автоматически скачивает актуальный `yt-dlp.exe` из официального GitHub-релиза при первом воспроизведении через yt-dlp и проверяет SHA-256 по манифесту этого релиза. Файл хранится в папке данных приложения; системный `PATH` не изменяется. Для использования собственного бинарного файла задайте `MUZICUS_YTDLP` до запуска MUZICUS. На Android внешний исполняемый файл yt-dlp не поставляется.

## Разработка

```bash
npm install
npm run tauri dev
```

Нужны Node.js 20+, Rust stable и MSVC Build Tools (Windows).

## Релиз

```bash
npm run release -- 0.2.0 "что нового"
```

Скрипт поднимает версию в `package.json`, `tauri.conf.json` и `Cargo.toml`, создаёт коммит и тег `v0.2.0`
и отправляет их в репозиторий. GitHub Actions собирает установщик для Windows и APK для Android и
публикует их в релизе.

Секреты репозитория:

| Секрет | Назначение |
|---|---|
| `TAURI_SIGNING_PRIVATE_KEY` | подпись обновлений Windows (`~/.tauri/muzicus.key`) |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | пароль ключа (пустой) |
| `ANDROID_KEYSTORE_B64` | release keystore в base64 |
| `ANDROID_KEYSTORE_PASSWORD` | пароль keystore |
| `ANDROID_KEY_ALIAS` | алиас ключа |
